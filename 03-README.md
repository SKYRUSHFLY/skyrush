# SKYRUSH

SKYRUSH is a **play-money crash-game website starter**.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Deploy

This project can be connected to GitHub and deployed with Vercel, Netlify, or another static hosting provider.

## Important

This starter is intentionally play-money only. It does not include real-money deposits, withdrawals, payment processing, or a system for manipulating game outcomes.
